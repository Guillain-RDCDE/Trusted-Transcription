# Real engine output on public-domain audio

Whisper run on real recordings, with the book they were read from as
the reference — no client data, nothing synthetic.

| | |
|---|---|
| Audio | *Les Contes de la Bécasse*, Guy de Maupassant, read for LibriVox (public domain), Internet Archive item `les_contes_de_la_becasse_0809_librivox`, 64 kb/s MP3 |
| Reference text | Project Gutenberg ebook #11714, one file per story, whitespace normalised |
| Engine | faster-whisper `small`, int8, CPU, language fixed to French, beam 5, word timestamps on |
| Files | `<chapter>.json` — the transcript in this project's format; `<chapter>.reference.txt` — the story's text; `labels.json` — what the detectors must do (nothing: a clean reading) |

`RESULTS.md` is generated by `report.py` and never edited by hand: the
engine bench (accuracy and production against the book) and the
detector bench (every flag on a clean reading is a false positive to
look at).

To extend the corpus, add chapters to `report.py`'s table, drop the
transcript in, and rerun. The audio itself is not committed; the
script downloads it from the Internet Archive.
